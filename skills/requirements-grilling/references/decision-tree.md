# 决策树与缺口处理

| ID | 待决策问题 | 依赖 | 已有证据 | 缺口类型 | 处理路径 | 结论与来源 | 状态 |
|---|---|---|---|---|---|---|---|

状态可用：未探索、调研中、待人判断、已确认、被后续决策取代。不要把工作假设标为已确认。

## 四类路径

- 已知的已知：主动收集目标、约束、反例；用具体行为复述共同理解。
- 已知的未知：列出不懂的问题、可选方案、所需证据，使用当前可用资料和搜索研究；需要学习时解释判断标准。另开会话只是可选手段，不假定能自动创建或控制会话。
- 未知的已知：用最小原型、样例数据或交互对比显露用户默认期待。原型结论才进入规格，原型自身不是生产实现。
- 未知的未知：说明缺少哪个领域的知识、应向谁询问、需要确认什么规则。可以草拟问卷，不自行给同事发消息。

这些类型是当前参与者视角下的分类，获得新知识后可以变化；同一问题也可能需要多种方式。

## 已有文档充分时

允许先产出带来源和不确定性标记的完整需求草稿，供用户补齐与修正。标明这是 Agent 提案；未知条件无法填补时退出并列证据，不能将自问自答视为人类共识。
